# 遊び方

1. フォルダを丸ごとダウンロードして、`.sln` を **Visual Studio 2022** で開く
2. **F5**（デバッグ開始）を押す

初回だけ「データベースを準備しています」と表示されます。データベースは自動で作られるので、設定は不要です。

## 「LocalDB に接続できませんでした」と出たとき

Visual Studio Installer を開く → 変更 → 「個別のコンポーネント」→ **SQL Server Express LocalDB** にチェック → インストール。その後もう一度 F5。

## 遊び方のメモ

- 左に事件の状況と目的。右のSQL欄に SELECT 文を書いて `Ctrl+Enter` で実行
- 「スキーマ」でテーブルの構成、「メモ帳」で捜査メモ、「メニュー」でヒントやBGM
- 分かったことを左下の欄に入力して提出
